## Freed v26.7.2500-dev

Freed Desktop gets the 3D Friends Galaxy, hands the cloud merge its own disposable worker so its peak memory goes back to the system, and starts pruning the archive again on machines with cloud sync connected

### Features

- Freed Desktop now renders Friends as a navigable 3D galaxy on WebGPU or WebGL2, keeping billboard labels readable while you pan, zoom, and focus
- Cloud sync now merges in a short-lived worker that Freed shuts down once the merge finishes, so the peak the merge needed goes back to the system instead of staying claimed for as long as the app runs. On a 15,846 item library that peak measured 1,356 MB
- Each device now keeps its own Friends layout, so dragging or pinning a person no longer moves them on your other devices

### Fixes

- Archive pruning runs again on machines with cloud sync connected. It used to be skipped outright whenever cloud credentials existed, so on a Drive-connected machine it never ran at all. It now waits for the first cloud reconciliation and then runs, along with feed-item dedupe and title healing
- Reading priority is now computed on each device instead of being synced, which takes it out of the merged document entirely
- Renderer memory readings now measure against a pre-hydration shell baseline, so the empty window's own footprint no longer counts against loaded content
- Freed now warns when more than one Freed Desktop is registered to make the same provider requests, and lets you acknowledge that warning per device
- Window controls on macOS now sit centered in the Freed titlebar
- Beta badges now stay beside their source names in the sidebar instead of wrapping onto their own line
- The local relay now rejects pairing tokens issued before a factory reset, including sockets that authenticated earlier
- Local AI settings no longer report a model lifecycle change when the on-device classifier only records telemetry
- Runtime health writes are now serialized inside Freed Desktop so concurrent updates cannot interleave
- Bundled Rust and PWA build dependencies moved to current patched versions
