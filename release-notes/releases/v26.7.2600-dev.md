## Freed v26.7.2600-dev

Lower cloud-merge memory, traceable renderer growth, and safer synced-library cleanup

### Features

- Cloud merges now run in a short-lived worker, releasing temporary memory after each merge instead of keeping it in Freed Desktop
- Renderer memory reports now separate startup overhead from loaded-library growth, making regressions easier to trace
- Cloud-synced libraries now run archive cleanup during reconciliation, preventing deleted history from accumulating indefinitely

### Fixes

- Cloud sync moves document payloads across the native boundary as compact encoded data instead of large number arrays
- Feed ranking no longer syncs device-specific recency data between devices
- Every synced field now has an explicit storage and deletion policy
- Large feeds can be projected into compact rows without losing source data
- Replaced a withdrawn Rust networking dependency used by Freed Desktop
- Historical cloud promotions are recognized again
- Facebook group state now stays aligned with the local library

### Known limits

- This build does not change the 4 GB renderer safety limit for Facebook or Instagram sync. Those providers can still pause when a large library pushes the renderer above that limit
- The new memory reporting measures where growth occurs. Moving the library corpus out of the renderer remains future work
