## Freed v26.10.701

Linux Library keys and more reliable joined-device sync

### Features

- Linux stores Library signing keys in an existing unlocked Secret Service vault and preserves the same identity across app and vault restarts
- Freed Desktop can join an existing Library as a consumer device
- Desktop and PWA devices catch up through incremental operations and report synchronization progress

### Fixes

- Locked or unavailable Linux vaults return an error instead of replacing Library keys
- Desktop retains sync ownership until canceled work has settled
- Drive credentials refresh during long PWA transfers; sync status reports active stages and the last successful completion
- Routine Library sync checks avoid counting every checkpoint record
- Annotation upgrades resume in bounded pages without losing the saved migration position
- Update notifications and Settings show Library backup preparation and elapsed time
- Desktop Settings shows the ten newest individual releases with complete notes
- Descriptions in sidebar tiles without media are centered

### Follow-ups

- Primary transfer and recovery remain disabled in ordinary builds. Synthetic acceptance uses the separate transfer-acceptance app and a matching-source PWA
- This release does not include the later strict Desktop viewer work or authorize a real Primary handoff
- Upgraded local Library catalogs require a compatible successor build; recovery preserves local state and proceeds forward rather than downgrading the database
