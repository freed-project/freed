## Freed v26.9.2900-dev

Cooperative Primary transfers and explicit recovery for offline consumer edits

### Features

- Freed Desktop can transfer Primary authority to another enrolled installation and resume the transfer after restart
- Desktop and PWA consumers can review archived edits and explicitly apply eligible changes again after an authority transfer
- The former Primary can join the successor as a consumer, and later transfers retain access to earlier recovery archives

### Fixes

- The source stops capture before authorizing a transfer, and the target stays fenced until it verifies the published successor
- Retrying a recovery action after a lost response returns its original replacement instead of creating a duplicate edit
- Recovery editors preserve complete transactions and compare archived values with current Library state before signing
- Closing or replacing an archive review cancels its pending native read
- An activated target can prepare a later transfer back to another enrolled installation

### Follow-ups

- This dev candidate requires end-to-end acceptance with two isolated Desktop installations and the matching PWA before moving the owner Library
- After transfer or recovery activates local schema 2, preserve the database and use a compatible successor build. Do not downgrade it with an older binary
- Headless authority transfer remains a separate delivery; unilateral headless promotion is refused
