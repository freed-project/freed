## Freed v26.8.1202-dev

Freed now runs its active Desktop Library on SQLite and its PWA Library on IndexedDB, with safer writer ownership and a resilient geographic map.

### Features

- Feed updates and Library actions now commit directly to native SQLite
- Freed Desktop now checks the active writer epoch before Library mutations or provider actions

### Fixes

- Prevented repeated full-Library SQLite sorting from pinning Freed Desktop CPU on large libraries
- Restored the geographic map background when its remote style document is unavailable
- Imported actor-bearing SQLite checkpoints without losing their authority metadata
- Fenced retired SQLite writers before they can publish changes
