## Cause

The contact sheet was generated from a 40-item ordered download list. Four candidates were then excluded while producing the 36-item JSON. The hand-authored visible-description array was paired to the shorter list without rebuilding the filename-to-record map. That offset made contact-sheet positions unsafe evidence for the final JSON records.

## Required re-admission method

1. Resolve the final catalog ID to its direct image URL.
2. Download it to a temporary filename that includes the catalog ID.
3. Open that exact file at full size.
4. Record only visible facts, then compare those facts with the live source page and source taxonomy.
5. Rebuild the contact sheet from the already-final ordered records. Never use its tile position as a substitute for the filename-to-record map.
