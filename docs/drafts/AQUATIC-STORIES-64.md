They do not provide the wrasse or other figure needed by the excluded encounter drafts. Camouflage, disputed resemblance and wanting to be found are already represented in admitted prose.

## Source and rights method

The live iNaturalist v1 API supplied observation and photo records. Source-published observation JSON supplied explicit `large_url`, author attribution and versioned Creative Commons license URLs. Each selected photo's license was checked separately from the observation-data license. Source metadata responses are saved beneath `/tmp/freed-aquatic-stories-64`.

The `large_url` files are published delivery variants, usually 1,024 pixels wide. Their dimensions, byte counts, SHA-1 and SHA-256 were measured from the exact viewed bytes. Original upload dimensions are retained separately; original upload hashes and an original-upload visual review are not claimed. No URL suffix was guessed and no locally resized image is proposed for delivery.

A photo JSON URL returned 404 and was not retried. The documented observation JSON route returned healthy responses and the explicit image URLs. No Commons or previously denied source endpoint was retried.
