# Avatar review 01

26 of 52 existing characters have a selected portrait. The other 26 remain unresolved. These are reviewer-selected candidates, not owner approval of the cast or corpus.

## Method

Reviewed actual centered circular crops in an isolated headless browser, at 210 or 260 CSS pixels. Reused existing catalog hotlinks. No image binaries were added to the repository and no integration files were changed. Review screenshots are local, disposable evidence in output/playwright/avatar-review-1.png through avatar-review-4.png. Live rendering at final tiny galaxy sizes still needs the integration review.

The mapping exports SAMPLE_CHARACTER_AVATAR_SHA1. Missing keys mean unresolved, never permission to pick a random subject match. Existing catalog records remain authoritative for URL, creator, license and dimensions. Their SHA1 identifies the source asset, not a hash of the transformed thumbnail. Nova and Colm are explicit existing non-animal cast exceptions.
