# Friends interface

## Contact tracking

Contact tracking is pending a complete user-facing workflow. Do not display last-contact timestamps or "Never contacted" status in friend profiles, overview cards, or compact selection cards until that workflow is available. Existing stored contact fields and reach-out records are preserved. Removing this status text does not delete contact data.

Reconnection reminders, outreach badges, follow-up counts, contact-based filters, and reach-out logging controls are also withheld until that workflow ships. The directory header contains search, result count, and sort controls above one divider; results below it scroll together. A nonempty search includes matching connections as well as friends, without changing their relationship status.
